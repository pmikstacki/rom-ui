# ROM UI gallery implementation plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Extract Flow and chat compositions and deploy the gallery to romui.cybernomad.it.
**Architecture:** Separate chat and optional Flow entry points. An independent gallery installs the packed archive and supplies synthetic data.
**Tech Stack:** Svelte 5.57.1, pnpm 10.30.0, Vite 8.3.2, Tailwind 4.3.3, Svelte Flow 1.7.0, Playwright 1.63.0.
**Spec:** docs/superpowers/specs/2026-10-09-gallery.md

## Global Constraints

Preserve public API paths and alpha.3 focus behavior.
Keep storage, model calls, authority and domain layout in hosts.
Use an optional Flow peer and an installed gallery archive.
Preserve historical evidence and unrelated active changes.

## Review Focus

- Pending completion after an authority change must not clear another draft.
- Composition confirmation must not submit a message.
- Responsive transitions must preserve the editor and its focus.
- Text and citations must not introduce HTML or unsafe links.
- Canceled fitting must not affect replacement graphs.
