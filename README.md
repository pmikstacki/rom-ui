# ROM UI

Reusable Svelte 5 controls extracted from ROM Studio.

The first candidate exposes `rom-ui/controls` and `rom-ui/styles`.
It preserves the existing controls without behavioral changes.
Client, discovery, authentication and durable mutation recovery remain in ROM.

This is an extraction candidate, not a published npm release.
ROM Studio migration and independent browser acceptance remain open.

Run `npm ci`, then `npm run check`.
Run `./scripts/check` for the installed consumer and browser checks.
